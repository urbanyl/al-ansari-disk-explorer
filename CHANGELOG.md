# Changelog

## 1.0.0 — 2026-10-29

First public release of **Al-Ansari Disk Explorer**.

### Added

- Fast native directory scanner with live streaming results.
- Largest files (top 1000) and largest folders (top 300) with aggregated sizes.
- Protected-file engine: system, program and application-data files shown in red.
- Deletion blocked when a protected file is selected (checked again by the deletion service).
- Recycle Bin deletion by default; permanent deletion with a stronger confirmation.
- Option to skip protected files and folders entirely during a scan.
- Deletion journal, selection summary, free-space display, open location and Recycle Bin access.
- Classic Win32-style English interface; no administrator rights, no telemetry.
